# Third-party notices

The two `.skill` archives include third-party SVG icon snapshots under `assets/icons/`. The original notices travel with each package and remain the authoritative license record.

The bundled icon families include:

| Library | Snapshot | License / note |
| --- | --- | --- |
| Bootstrap Icons | 1.11.3 | MIT |
| Lucide | 0.469.0 | ISC |
| Tabler Icons | 3.46.0 | MIT |
| Phosphor Icons | 2.1.1 | MIT |
| Simple Icons | 16.28.0 plus compatibility files | CC0 for the project; individual brand marks may have separate trademark or usage requirements |

For the complete attribution text, version details, compatibility aliases, and trademark guidance, extract either package and read:

```text
assets/icons/THIRD_PARTY_NOTICES.md
```

The product Skill instructions and the third-party icon assets have separate licensing boundaries. The Skill package does not override the license, attribution, brand, or trademark requirements of the bundled icon libraries.
